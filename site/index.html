01 / 精度基线

BF16 / FP16

作为浮点精度参考，观察数值稳定性与资源开销。浮点精度基线与低比特量化分开比较。

02 / 低比特加载

INT8

以 8-bit 权重加载为对比方向，分析精度与显存折中；额外适配参数与量化基座分别处理。

03 / 4-bit 微调

NF4 / FP4

当前微调路径采用 NF4 + QLoRA；FP4 作为表示方式的对比候选，并区分权重存储与计算精度。

04 / 推理部署候选

AWQ / GPTQ

面向训练后权重量化的扩展方案，结合校准样本、模型支持情况与推理内核验证部署可行性。
